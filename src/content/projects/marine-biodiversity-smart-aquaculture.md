## Overview

This work builds monitoring platforms for marine biodiversity conservation and smart aquaculture. The systems combine underwater cameras, bioacoustic sensing, water-quality measurements, edge devices, server infrastructure, and operational deployment planning.

## Role

Minh-Hoang leads technical development teams responsible for embedded systems, underwater sensing stations, servers, and deployment infrastructure. The work includes architecture design, technical reviews, task allocation, system validation, and deployment preparation.

## System Stack

The platform connects field sensing nodes with communication services, backend storage, AI modules, and data-management workflows so researchers can operate outside laboratory conditions.
